## 후속 개선

- 블로그/프로젝트 목록은 클라이언트 쿼리에 의존한다. 첫 페이지 서버 렌더링과 실제 링크 기반 페이지네이션을 도입해 크롤러가 목록과 내부 링크를 즉시 발견하도록 개선한다.
- 상세 페이지는 메타데이터와 본문에서 자기 API를 호출하며, 해당 GET API는 조회수를 변경한다. 읽기 전용 서버 데이터 함수를 분리하고 유효하지 않은 ID의 404 응답을 검증한다.
- Notion 속성 ID 하드코딩을 스키마 이름 기반으로 바꾸고, 실제 게시일·수정일·작성자가 검증된 BlogPosting JSON-LD를 도입한다.
- Notion 조회수 변경도 last_edited_time에 영향을 줄 수 있으므로 장기적으로 콘텐츠 수정일을 별도로 관리한다.
- Search Console에서 www 도메인의 sitemap.xml을 제출하고 색인 제외 사유, 검색어, 클릭률을 확인한다.
- 실제 모바일 Lighthouse 및 CrUX/Core Web Vitals로 이미지·폰트·JS 성능 병목을 측정한다.

Search Console, 검색 순위, 실제 방문자 성능 데이터는 이번 점검에 포함되지 않았다. SEO 점수나 순위 상승 수치를 추정하지 않았다.
